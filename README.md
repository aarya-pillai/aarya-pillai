## what i've been building ✦

### 📊 Revenue Quality Analytics Pipeline

**DuckDB · dbt · SQL · Power BI**

> **Where are we losing revenue, and why?**

Built an end-to-end analytics pipeline across **70K+ transactional records** to investigate revenue retention, discount dependency, refunds, and product performance.

* Built a layered **ELT pipeline** from staging → intermediate transformations → analytical marts
* Created **12+ dbt models** for reusable business metrics and analysis
* Used **SQL** to investigate revenue loss, retention, discount behavior, and refund patterns
* Built an interactive **Power BI dashboard** to turn the results into actionable insights
* Added data validation and documentation to make the pipeline easier to understand and maintain
